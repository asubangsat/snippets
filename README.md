# pykit

Small collection of Python utility helpers I use across projects.

No dependencies, just the standard library.

## Install

```bash
pip install -e .
```

## Modules

- `pykit.strings` — string helpers (slugify, truncate, etc.)
- `pykit.dates` — date/time helpers
- `pykit.collections` — list/dict helpers
- `pykit.numbers` — number formatting and math helpers

## Running tests

```bash
python -m pytest tests/
```
